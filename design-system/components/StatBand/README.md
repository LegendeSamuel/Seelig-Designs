# StatBand

A single rounded band of large, Extra-Light amber numbers with small labels — the About page's facts.

## What you provide
- `<div class="about-stats">` with 2–4 `<div class="stat"><span class="stat-number">…</span><span class="stat-label">…</span></div>`.
- Real, verifiable numbers only ("6+" years, "100+" shoots, "8" genres). Never invent figures.

## Values
- Band: `fill-subtle`, 1px `line-subtle`, `radius-xl`, padding `space-6 space-4`, gap `space-6`.
- Number: `stat` style (56px/200/leading 1) in `amber`; 44px under `bp-md`.
- Label: 16px, `text-label`, 0.5px tracking, 0.75rem above.
